# Larger-scale environment design — proposal

This is a design backlog, not a claim that every item has shipped. The current implementation is described in [WORKSHOP.md](../WORKSHOP.md) and the [roadmap](../ROADMAP.md).

- [ ] Connect local fields into recognizable system-scale regions: fractured ice belts, branching debris streams, dust channels and quiet transitions.
- [ ] Add distinctive landmarks such as split asteroids, derelict shipyards, broken orbital complexes, stone arches and mirror/sail arrays.
- [ ] Tie composition, material, scale and damage to a coherent regional identity rather than colour changes alone.
- [ ] Preserve readable navigation, safe travel routes, physical scale and HIGH/LOW budgets.
- [ ] Evaluate resource lifecycle and actual visual variation with matched views before expanding density.

Existing deterministic fields, libraries, layered planets and scene editing provide a foundation. New hazards, mining, rewards and economy require a separate gameplay decision.
