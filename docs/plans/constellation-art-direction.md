# Constellation artwork — retired

The owner cancelled visual constellations on September 19. All 88 runtime illustrations and their display/label/territory code were removed. Old line rendering was not restored. This is historical design context, not an active implementation plan.

The previous proposal used generated transparent engraved figures facing each viewer, assigned deterministically to planetary territories rather than changing with camera direction. It was reviewed and then explicitly withdrawn.

Do not restore it as part of unrelated generation, documentation or deployment work. Underlying retained source data keeps its attribution in THIRD_PARTY_NOTICES.md.
