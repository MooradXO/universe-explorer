# Объединённая карта: AT-HYG, Gaia DR3, SIMBAD и NASA NED

Дата: 15 сентября 2026. Статус: полный AT-HYG импортирован, локальные поиск и 3D-карта подключены. Gaia/SIMBAD/NED доступны небольшими запросами из карточек и поиска, с кешем на E. [Результат спринта данных](../phases_archive/catalog-import-2026-09-15/README.md), [карта](../phases_archive/star-map-2026-09-15/README.md), [подключение источников](../phases_archive/online-catalog-2026-09-15/README.md).

## Утверждённый результат

Большая объёмная карта с вращением, приближением, поиском и выбором системы. Пользователь подтвердил намерение использовать полный AT-HYG 4.0 для локальной разработки и расширить его Gaia DR3, SIMBAD и NASA NED. NASA RED в сообщении означает NED из предыдущего обсуждения.

Последнее уточнение пользователя: не скачивать гигабайты научных архивов. Утверждены компактная основа мира и дополнительные сведения через интернет по мере исследования с ограниченным кешем. Поэтому Gaia/SIMBAD/NED подключены по запросу, а массовая выгрузка отменена. Существующая подготовка AT-HYG (~13 GB с повторной проверочной базой) остаётся на E; браузер получает только нужные блоки. Ни один каталог не даёт полного описания Вселенной или подробной планетной системы для каждой записи.

## Роли источников

| Источник | Роль в общей карте | Особенность |
| --- | --- | --- |
| AT-HYG 4.0 | Первая полная основа звёздной карты, исторические идентификаторы и имена | Уже использует Gaia; объекты нельзя повторно добавлять как независимые звёзды |
| Gaia DR3 | Расширение звёздного слоя, астрометрия и показатели качества | Не для всех источников есть параллакс; параллакс с большой ошибкой не даёт надёжного расстояния простым обращением |
| SIMBAD | Дополнительные имена, типы объектов, библиография, сведения о туманностях и скоплениях | Сопоставляет идентификаторы; одна запись может описывать систему или скопление, а не отдельную звезду |
| NASA NED | Внегалактический слой: галактики, квазары, группы и их измерения | Различать измеренные расстояния и оценки по красному смещению; модель расчёта хранить явно |

Первичные источники: [AT-HYG](https://codeberg.org/astronexus/athyg), [Gaia DR3](https://www.cosmos.esa.int/web/gaia/dr3), [SIMBAD contents](https://simbad.cds.unistra.fr/Pages/guide/ch15.htx), [About NED](https://ned.ipac.caltech.edu/Documents/Overview).

## Предлагаемая модульная архитектура

`scripts/catalog/`, общий контракт, поиск, файлы областей, browser loader и `src/ui/star-map/` реализованы. Three.js представление находится отдельно в `src/world/star-map/`; render loop остаётся в Engine. [Команды и формат локальной базы](../CATALOG_PIPELINE.md).

- `scripts/catalog/`: загрузка, проверка checksum, отдельные адаптеры AT-HYG/Gaia/SIMBAD/NED, нормализация, сопоставление и построение файлов по областям. Подготовка вне браузера.
- `src/catalog/`: общий контракт, индекс поиска, чтение manifest и загрузка видимых областей. Не зависит от материалов Three.js или управления кораблём.
- `src/ui/star-map/`: интерфейс и управление картой, список результатов, выбор объекта и карточка происхождения данных.
- `src/world/space/`: существующий streaming/floating origin получает подготовленные локальные координаты. Расчёты астрономических расстояний не размазывать по WorldBuilder и ShipController.
- Исходные выгрузки в `project/.catalog-research/` вне game repo; производные локальные данные с отдельными source manifests. Не включать исходные архивы автоматически в `public/` или git.

Запись общего каталога должна хранить собственный устойчивый ID, тип объекта, список ID источников с версией/датой снимка, имена, координатную систему/эпоху/единицы, происхождение измерений и оценку качества. Gaia ID и другие длинные идентификаторы — строки. Наблюдения, вычисленные оценки и процедурное содержание имеют разные признаки происхождения.

## Как избежать повторов и неверных совпадений

Сначала сопоставлять подтверждённые идентификаторы соответствующего релиза. Для AT-HYG 4.0 подтверждён DR3 у Gaia ID по STEPS_V4.txt; источник дистанции при этом может быть DR2. При полном импорте обнаружены 1 163 Gaia ID с несколькими соответствиями — их не сливать автоматически. Совпадение чисел между разными релизами не считать достаточным. Затем использовать опубликованные таблицы соответствий и альтернативные имена. Сопоставление только по соседству на небе — кандидат на проверку с учётом эпохи, собственного движения и погрешностей, а не автоматическое слияние.

Двойные звёзды, компоненты систем, скопления и галактики могут давать связи один-ко-многим. Сохранять эти связи и конфликтующие измерения; близость не доказывает тождество. [Ограничения cross-match Gaia](https://gea.esac.esa.int/archive/documentation/GDR3/Catalogue_consolidation/chap_crossmatch/sec_crossmatch_algorithm/).

Для неизвестной дистанции не выдумывать XYZ: пользователь выбрал поиск и карточки без 3D-точек. Красное смещение не является готовой декартовой координатой; для далёких галактик потребуется согласованная космологическая модель и определение расстояния.

## Технические условия подключения

SIMBAD и NED — обновляемые базы: сохранять запрос, дату выгрузки и источник каждого значения. Использовать пакетные запросы и локальный кеш, а не обращаться к научным API для каждой звезды в каждом кадре.

NED сообщает, что legacy API устарели и не видят данные, добавленные после января 2026. Для адаптера использовать [новый API](https://ned.ipac.caltech.edu/Docs%3A%3AAPI/) и проверить [ограничения автоматических запросов](https://ned.ipac.caltech.edu/Documents/Overview) перед массовой выгрузкой.

Новые сведения запрашиваются только явным действием изучения/поиска. Локальный сервер ограничивает ответ 512 KiB, очередь восемью различными запросами и весь дисковый кеш 32 MiB. Устаревший снимок при недоступности сервиса помечается в интерфейсе. Текущие данные дополняют карточки; новые 3D-координаты и модели объектов из них пока не строятся.

Пользователь сохраняет возможность монетизации, понимает риск отсутствия разрешения и поручил сейчас не отправлять запрос ESA. Данные не публиковать в коммерческом релизе до разрешения. [Проверка условий](real-map-options-2026-09-15.md), [неотправленный черновик](esa-gaia-permission-request-draft.md).
