# Real star-map options — recorded decision

Decision date: September 15. The selected direction was a large 3D catalogue map with rotation, zoom, search, system selection and detailed exploration of chosen systems. AT-HYG 4.0 was chosen for the base; Gaia DR3, SIMBAD and NASA/IPAC NED complement it with explicit small requests. The project owner wished to preserve future monetization options.

The complete pinned AT-HYG import was verified locally. Later clarification rejected bulk scientific-archive downloads in favour of bounded on-demand observations. Free in-system flight, fast fictional cruise, interstellar warp and an Earth base were accepted separately.

Scientific coordinates and uncertainties must remain identifiable. Unknown distances are searchable metadata, not fabricated 3D points. Repeated source IDs can describe multiple components; equinox is not observation epoch, and derived radial distances require appropriate scientific interpretation.

At the time of research, the compilation declared CC BY-SA 4.0 and Gaia source terms included CC BY-NC 3.0 IGO. Commercial-use permission was not obtained. A draft request was prepared but not sent. The project code license does not resolve source-data rights. Current operational instructions are in CATALOG_PIPELINE.md; this file records the decision rather than fresh legal guidance.
