Максимальная исходная дистанция — 941129.7121 pc; такие значения не принимаются автоматически за надёжные сведения о далёкой звезде. Неопределённость отмечена в отчёте и контракте.

## Реализация

- `src/catalog/CatalogTypes.ts`: единый контракт с версией, источниками, строковыми ID, координатами, фотометрией, движением и признаками качества.
- `src/catalog/adapters/AthygRecord.ts`: независимая от Three.js нормализация. DR3 у ID не подменяет отдельный источник дистанции DR2/DR3/Hipparcos и т.д.
- `scripts/catalog/`: восстановимая загрузка Git LFS, потоковый CSV, SQLite, отчёт, независимая проверка. Новых зависимостей нет; используется Node 24.
- `tests/unit/catalog.test.ts`: 11 новых тестов/сценариев; повреждённые архивы, повторные ID, отсутствующие координаты, CSV на границах блоков и воспроизводимость.
- Команды и устройство данных: [CATALOG_PIPELINE.md](../../CATALOG_PIPELINE.md).

На E сохранены исходный gzip и два независимых подготовленных результата в `project/.catalog-research/athyg-4.0/`. Основной результат — `prepared-v1`. Один рабочий SQLite-файл занимает 5 446 770 688 bytes: он содержит исходные поля и нормализованный JSON и предназначен для подготовки компактного набора карты, а не для загрузки браузером.

## Проверки

- SHA256 полного исходника совпала с закреплённым Git LFS объектом; размер 199 688 001 bytes. Проверка gzip CRC при импорте прошла.
- Два полных импорта дали одинаковые канонические записи, набор отклонённых строк и побайтово одинаковые SQLite-базы.
- Независимый verifier перечитал весь набор, проверил целостность SQLite, учёт строк, отсутствие выдуманных XYZ и точное совпадение всех сохранённых Gaia ID с исходными строками.
- На 355 распределённых по каталогу строках проверено преобразование RA/Dec в XYZ. Максимальное отклонение 0.00010720139065274169 pc, в пределах выбранного численного допуска округления. Направления остальных строк отдельно не перепроверялись.
- Полные импорты: 141.784 s и 141.664 s; измеренный пик RSS 347 869 184 и 352 690 176 bytes. Это замеры данного компьютера.
- 29 unit tests PASS, TypeScript/space-only guard/build PASS.
- Production preview отвечает HTTP 200. App chunk остался 223.35 kB / 66.14 kB gzip; новый код каталога не подключён к runtime.
- Browser smoke повторно не запускался: интерфейс, сцена и игровой runtime в этом спринте не менялись. Прежние 10 browser tests относятся к секторному спринту.
