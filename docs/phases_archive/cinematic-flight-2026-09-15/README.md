# Cinematic flight presentation

Introduced cinematic space presentation while retaining flight controls, physical scale and catalogue positions. HIGH/LOW budgets, lighting and atmosphere were checked in isolated browser views. Visual styling is illustrative and does not change astronomical records. Later environment and warp stages expanded this direction.
