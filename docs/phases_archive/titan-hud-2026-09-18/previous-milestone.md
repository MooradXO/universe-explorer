# Current Milestone

## Генератор индивидуальных визуальных окружений

Основная игра Universe Explorer. Пользователь разрешил генератор и прямо исключил новые игровые механики, журнал, пробы, тайминги и UI выбора зон. Сохраняются кинематографичный стиль, реальные координаты и радиусы. Git, публикация и прежний Windows ZIP вне задачи.

[Устройство и фактический объём](../project/universeproject%20(2)/docs/research/environment-implementation-2026-09-17.md). [Evidence](../project/universeproject%20(2)/docs/phases_archive/environment-2026-09-17/README.md). Предыдущие acceptance сохранены в previous-milestone.md рядом с evidence.

## Acceptance

- [x] Независимый детерминированный профиль; контроль повторов поверхностей, объектов, размещения и явлений между соседями.
- [x] 64 рецепта поверхности, 128 обработок материала; отдельные карты солнечных планет, генеративные детали и освещение рельефа.
- [x] Облака, атмосферы, сияния, разнообразные кольца и спутники; отсутствие элементов тоже предусмотрено.
- [x] 192 формы природных объектов, 48 схем распределения, 192 конструкции и 32 визуальных явления; разные положения областей при свободных точках прибытия.
- [x] 12 вариантов дальнего фона, включая отсутствие; земное свечение сохранено, другие формы/цвета/масштабы/движение.
- [x] 66 Epic-пресетов, ленивые загрузки и budgets; исходная библиотека пользователя сохранена.
- [x] Наполнение между планетами: постоянные ячейки, меняющаяся плотность, природные поля, редкие сооружения/явления и дальние силуэты; bounded streaming.
- [x] Новые механики и интерфейс исследования исключены; генератор подключён в основную игру.
- [x] 67 unit tests, TypeScript, space-only guard и production build.
- [x] HIGH/LOW маршрут Земля → Марс → Проксима → база, восстановление сохранения и повторные перелёты без роста GPU-ресурсов.
- [x] Финальная визуальная проверка 64 поверхностей, 66 FX и 32 миров непосредственно в игре; HIGH/LOW, управление и прежние сцены.
- [x] Проверка непрерывного полёта между планетами, возвращения в ячейки, скорости круиза и ресурсов HIGH/LOW.
- [x] Проверенная сборка установлена в основной preview с сохранением ресурсов уже открытого полёта.

## После проверки

Пользователь самостоятельно оценивает результат в игре. Дальнейшие исправления — по конкретному визуальному замечанию. Продуктовые механики не входят в эту милю; общие будущие направления остаются в ROADMAP.
