# Continuous star-map view

Improved map continuity while changing levels of detail, reopening views and selecting destinations. Existing map blocks remain visible until replacements are ready, and selection/camera state is coordinated with asynchronous requests.

Verified desktop HIGH and mobile LOW map behaviour, navigation and repeated opening in isolated browser contexts. The scientific catalogue and linear distance convention were preserved. The implementation did not introduce constellation artwork or fabricate missing positions.
