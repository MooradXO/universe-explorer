# Первый маршрут по каталожным системам

Дата: 2026-09-15. Рабочая копия и данные на E. Игра: http://127.0.0.1:3001/.

## Результат

Обычный вход теперь запускает корабль у игровой базы возле Земли. Навигация справа выбирает объект системы и запускает крейсерский режим. КАРТА → поиск звезды → «Варп к звезде» меняет активную систему, планеты, фон и адрес корабля. Кнопка WARP в верхней панели возвращает на базу в Солнечной системе. Новые продуктовые решения пользователя: реальные пропорции расстояний, быстрый крейсерский полёт, старт в Солнечной системе, процедурные миры и места исследования с явной игровой пометкой.

Маршрут HIGH/LOW проверен на настоящем локальном каталоге: Земля → Марс → Proxima Centauri (AT-HYG 1440825) → орбитальная точка → возврат на базу. Перезагрузка на Проксиме при отключённых научных API восстанавливает тот же адрес. В орбитальном журнале хранятся последние 128 исследованных точек; сканирование не создаёт вымышленных научных измерений и не меняет экономику.

Это первый игровой маршрут по каталогу. Полная художественная переработка, наблюдательные модели экзопланет, галактические слои и разнообразные сценарии исследования ещё впереди. Gaia/SIMBAD/NED по-прежнему дают отдельные сведения по запросу; их измерения не подменяют координаты AT-HYG автоматически.

## Данные и масштаб

- Восемь планет Солнечной системы: малые числовые таблицы JPL, без архивов текстур. Позиции рассчитаны по эллиптическим орбитам для J2000.0, а не для сегодняшнего дня. Земля использует приближение барицентра Земля–Луна. Спутники в этом спринте не моделируются.
- Один линейный масштаб для расстояний и радиусов небесных тел: 1 unit = 10 км; 1 а.е. = 14 959 787,07 units. Модели кораблей/базы остаются игровыми. Скорость крейсерского режима — игровая, до 0,5 а.е./с, с замедлением у объектов. Межзвёздные переходы занимают 2,4 с игрового времени.
- Для остальных звёзд — четыре стабильных процедурных мира на seed `catalogue-systems:v1:<AT-HYG ID>`. Названия, карточки и точки исследования отмечены как игровые; существование этих планет не утверждается. Радиусы звёзд, кроме номинального солнечного, иллюстративные.
- Поверхности всех планет процедурные и иллюстративные. Даже Земля не использует фотографическую карту поверхности. Кольца и облака — художественное представление.
- Фон — ограниченная выборка того же AT-HYG, направления пересчитаны относительно выбранной звезды. Не более 24 000 точек HIGH / 12 000 LOW, корневой блок + до 6/3 ближайших листьев. Это выборка, не все 2,5 млн звёзд одновременно. Межпланетный параллакс фона пока не учитывается. Палитра и яркость приблизительные.
- Полные планеты строятся по одной, максимум 4 HIGH / 2 LOW в радиусе 80 000 units. Дальние планеты представлены навигационными точками; звезда проецируется в доступный диапазон камеры с сохранением углового размера. Дальняя проекция не участвует в физических столкновениях снарядов.

## Архитектура

- `StellarAddress.ts`: неизменяемый адрес `{anchor, local: {sector, offset}}`, строковые каталожные ID и качества источника. Межзвёздные parsec XYZ не складываются с близкими координатами корабля.
- `world/systems/`: орбиты, SolarSystemData, чистые descriptors, CruiseMotion, SystemScene, CatalogSky, StellarTravel и FlightSave. WorldBuilder применяет переходы и связывает существующий бой, renderer и управление.
- `SystemNavigationUI.ts` и отдельный CSS: выбор цели, крейсерский режим, сведения/происхождение объекта, исследование орбиты, сворачиваемая мобильная панель. StarMapUI получает только callback варпа и ID текущей системы.
- Сохраняется hull/shield при варпе; старые снаряды и боты очищаются при переходе. Попадание/смерть отменяет подготовку варпа. Крейсерский полёт уступает стрельбе, ручному управлению, близкому бою и карте; движение проверяется по отрезку, чтобы не пересечь планету/звезду.
- Локальное сохранение `universe:stellar-flight:v1:<profile|guest>` включает систему, положение, ориентацию, посещённые точки. Гостевой ключ стабилен. Старые три Supabase XYZ сохранены без изменения, но не используются как новый адрес. Облачной синхронизации новых адресов пока нет.
- В gameplay-пакеты Realtime добавлен `systemId`, чтобы одинаковые локальные XYZ в разных системах не смешивали игроков, выстрелы и попадания. Старые fixtures без systemId остаются изолированной группой. Глобальный чат сохранён. Проверка транспорта автоматическая; живой бой двух Supabase-аккаунтов не проводился, backend локально не настроен.
- Старые `spaceSmoke=...` сцены сохранены для проверки регрессий секторов. Они не являются обычным запуском игры; новая серия `stellar-flight.spec.ts` запускает реальную новую Солнечную систему.

## Проверки и evidence

- Build / TypeScript / space-only guard PASS; 53 unit tests PASS.
- `desktop-high-route.json`, `mobile-low-route.json`: настоящий маршрут, сохранение и восстановление без API.
- `*-earth.png`, `*-mars.png`, `*-proxima.png`: визуальный контроль HIGH / mobile LOW.
- Полная серия: 22/22 browser tests PASS (5,4 мин), включая прежние 18 сценариев и четыре новых HIGH/LOW. Повторные переходы не увеличивают geometry/texture counts: HIGH 29/14, LOW 23/13. После уточнений положения личных баз и сообщения о недоступном фоне ещё 2/2 маршрута HIGH/LOW PASS. Финальная CSS-проверка мобильного экрана: панель заканчивается на y=300, FIRE начинается на y=311; `mobile-final-layout.png`.
- Final bundle: app 257,06 KB / 77,67 KB gzip, lazy map 25,24 KB / 9,55 KB gzip; новые архивы или библиотеки эффектов не добавлены.
- Сравнение четырёх старых named scenes с исходным baseline: 5% relative budget PASS. Это регрессионные fixtures; headless FPS не является обещанием производительности телефона. Новые системы имеют отдельные route/repeat snapshots.

В ходе проверки исправлены скрытие новой панели общим `.hud-panel` CSS, перекрытие объектов дальними звёздами и устаревшее ожидание 80 планет при обычном входе. Новый тест независимых клиентов сравнивает восемь одинаковых планет Солнечной системы.

Данные AT-HYG и 32 MiB online-cache остаются на E вне public/dist. Большие научные выгрузки не выполнялись. Публичная упаковка компактной основы и серверный API для сайта остаются отдельным этапом. EpicToonFX ещё не подключена: этот спринт использует уже имеющиеся средства Three.js. Коммита, push, публикации и отправки писем не было.

## Первичные источники

- [JPL — Approximate Positions of the Planets](https://ssd.jpl.nasa.gov/planets/approx_pos.html): элементы и формулы для J2000.
- [JPL — Planetary Physical Parameters](https://ssd.jpl.nasa.gov/planets/phys_par.html): средние радиусы восьми планет.
- [JPL — Astrodynamic Parameters](https://ssd.jpl.nasa.gov/astro_par.html): астрономическая единица.
- [IAU 2015 Resolution B3](https://www.iau.org/common/Uploaded%20files/IAUGA2015-Resolution-B3-recommended-nominal-conversion.pdf): номинальный радиус Солнца 695 700 км.
- [AT-HYG / David Nash, Astronomy Nexus](https://codeberg.org/astronexus/athyg): звёздные позиции. Атрибуция и прежние ограничения распространения сохранены в THIRD_PARTY_NOTICES.md; пользователь отложил обращение к ESA.
