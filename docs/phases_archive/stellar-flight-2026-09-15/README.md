# First catalogue-system route

Implemented Earth → Mars → Proxima Centauri (AT-HYG 1440825) → orbital site → home, with HIGH/LOW verification against the real prepared catalogue. Reload at Proxima restores the same address without external scientific APIs. The local orbital journal retains 128 entries and does not invent scientific measurements or rewards. Celestial distances/radii use 10 km/unit; 1 AU is 14,959,787.07 units. Ships remain gameplay-scaled. Cruise is fictional, up to 0.5 AU/s; warp lasts 2.4 seconds. Full planet budgets were four HIGH/two LOW within 80,000 units, created incrementally. Damage/death cancels preparation, and swept movement avoids solid bodies. Original system-ID transport tests were local mocks; live authority was introduced later with Colyseus.
