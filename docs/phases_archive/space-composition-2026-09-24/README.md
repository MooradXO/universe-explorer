# Space composition

Improved the relationship between background, orbital scenery and the ship's view. The stage focused on readable large-scale structure and varied layers rather than increasing every scene's object count.

Matched HIGH/LOW views and travel regressions checked composition, resource lifecycle and consistency while moving between systems. Catalogue positions, collision fields and established world identity remained separate from artistic presentation. External references informed direction only; their assets were not added to the game.
