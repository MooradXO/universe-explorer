# Список планет, ощущение полёта и согласованные FX — 16 сентября 2026

## Что изменилось

- `SystemObjectPicker` заменяет native select устойчивым списком внутри системной панели. HUD не пересоздаёт список и не меняет его раскрытое состояние. Выбор мышью/касанием, стрелки, Home/End, Enter, Escape, Tab и поиск по началу имени; закрытие снаружи и освобождение обработчиков. `SystemNavigationUI` отвечает за остальную панель.
- Исходный баг native select **не воспроизвёлся** в headless Edge: фактический `:open` оставался true 1,4 с и с guard присваивания disabled, и без него. Поэтому повторные присваивания disabled не объявлены доказанной причиной. `dropdown-probe.json` сохраняет baseline. Регрессия новой реализации проверяется настоящим кликом/касанием, ожиданием через несколько обновлений HUD и выбором видимого option; selectOption здесь не используется.
- `FlightDust` заменяет прежние редкие линии, отсутствовавшие в LOW. Ближний объём ±620 units содержит 900 частиц HIGH / 420 LOW; две общие геометрии и два draw calls, без текстур и новых объектов в кадровом цикле. Головки видны при обычном полёте; экспозиционные следы растут по фактической скорости. На крейсерской скорости мелкие точки плавно исчезают во избежание мерцания, длина следа ограничена 75 units.
- Частицы — явно художественная пыль для ориентации, не звёзды AT-HYG. Смещение берётся из разности положений корабля после cruise и recenter. Поворот камеры не создаёт поступательного движения. При остановке нет искусственного дрейфа. Floating origin переносит предыдущую позицию; relocation/warp сбрасывает измерение, варп скрывает ближний слой.
- `ApprovedFlightFX` лениво подключает только три согласованных пресета: SpinPortalBlue при варпе, ScanExplosion по кнопке исследования орбиты, Plexus у существующей игровой орбитальной точки. Одновременно максимум два эффекта; HIGH ≤700 частиц на эффект, LOW ≤260; per-emitter 280/110; groundY:null, sound:false, prewarm:false. Варп убирает сканирование и аномалию. Устаревшие загрузки освобождаются по generation token.
- LOW density установлен в .55: при .45 upstream округляет одиночное испускание до нуля, полностью убирая Plexus. Это выявил route test с проверкой ненулевого числа частиц, а не только успешной загрузки.
- `EpicEffectSpace` выполняет симуляцию в собственных единицах пресета и масштабирует весь её результат в игровые единицы. Это сохраняет исходное соотношение размера, скорости и trail histories: у upstream world-space emitters один options.size не масштабирует скорость, из-за чего Plexus сначала получался почти точкой. При floating origin переносится только anchor, истории частиц остаются в малом локальном пространстве. Vendor JS, declarations и исходная библиотека на C не изменены.

## Варианты новых локаций — ожидают выбора

[Интерактивные эскизы в LAN](http://192.168.100.182:3002/visual-lab.html?locations=1).

1. **Ледяное кольцо:** газовый гигант, несколько слоёв льда, крупные фрагменты и промежутки для исследования.
2. **Заброшенная верфь:** разорванные доки, фермы, корпуса и сигнальные огни, пролёт через сооружения.
3. **Ионный разлом:** локальные газовые слои, тёмные осколки, дуги и ядро аномалии.

Это пространственные эскизы с условными расстояниями, не финальные игровые ассеты. Общие кинематографичные материалы планет сохранены. Есть непрерывный пролёт, ручное вращение/zoom, HIGH/LOW, телефон portrait/landscape. Эти новые локации **не установлены в основной игре**. **Пользователь ответил: трёх существенно мало**, требуются индивидуальные поверхности, кольца, атмосферы, объекты, аномалии и свойства окружения каждой планеты. Предыдущий выбор трёх больше не является активным предложением; обновлённый разбор: `docs/research/environment-diversity-2026-09-16.md`.

## Проверки

- Build PASS; 58 unit tests PASS, включая движение вперёд/назад/вбок, неподвижность, большие cruise offsets, floating origin, warp reset и независимость симуляции EpicFX от положения/масштаба anchor.
- Route HIGH/LOW PASS: база → Марс → сканирование → портал → Проксима/Plexus → offline restore → возврат; проверены ненулевые частицы, budgets и пыль после смены системы.
- Повторные системы HIGH/LOW PASS: три возврата дают HIGH 38 геометрий / 15 текстур, LOW 33 / 14; нет накопления. Файлы `*-route.json`, `*-repeat.json`.
- UI: открытие указателем/касанием, ожидание 1,75 с через обновления HUD, выбор Марса, keyboard commit/cancel, скролл к Нептуну на телефоне. Portrait основного игрового HUD по прежним правилам требует поворота устройства; тест проверяет blocker и возврат в landscape.
- Браузерные тесты движения используют реальные keyboard / joystick events, последовательные состояния и кадры: обычный вперёд/назад/вбок, чистое вращение без движения пыли, boost. Мобильный профиль — эмуляция Edge; физический телефон пользователя удалённо не проверялся.
- Эскизы: пролёт меняет позицию камеры, пауза её удерживает, drag меняет ракурс, качество переключается, повторные rebuild не накапливают ресурсы. Исходная style-lab остаётся отдельной и работоспособной.
- LAN: игра, visual-lab, прямой переход с другой страницы — 200; foreign API/origin — 403; POST — 405. Старые процессы preview 3001/LAN 3002 переиспользованы; фокус окон не менялся.

Сводка: 18 browser scenarios PASS по финальным целевым прогонам (4 feedback, 4 route/repeat, 2 locations, 4 legacy scenes, 4 style/entry). Дополнительный mobile boost тест исправлен: TouchBoostOn требует также направления от joystick; повтор PASS. Тест паузы эскиза использует допустимую числовую погрешность матриц вместо точного сравнения float. Legacy performance comparison с `stellar-flight-2026-09-15/legacy-flight` укладывается в 5%: HIGH draw calls +1, LOW +2, число треугольников неизменно. Headless FPS не является замером физического телефона.

## Ограничения

Научные координаты/радиусы/орбиты, механика движения, backend и Realtime не менялись. Новые эффекты — только визуальное сопровождение уже существующих действий; отдельной системы помех/опасностей и новых наград за аномалию пока нет. Общий дальний газовый фон и однотипные орбитальные поля пока остаются; полное разнообразие окружений требует выбора и последующего переноса локаций. Commit/push, публикации, письма и научные выгрузки не выполнялись.
