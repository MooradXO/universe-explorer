# Weapon audio provenance

Weapon sounds are synthesized by Universe Explorer code in src/core/WeaponAudio.ts and integrated through SoundManager. They are original procedural output; no audio recording, soundtrack or sound-bank asset from a reference game is included.

External references were used to discuss timing, weight and spatial character only. Browser verification records actual game firing and synthetic test audio. Local recordings are verification artifacts, not runtime assets.

The procedural implementation follows the project's code license. Other visual resources retain their separate attribution in the root THIRD_PARTY_NOTICES.md.
