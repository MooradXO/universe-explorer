# Варианты окружения и проверка EpicToonFX

Подготовлена интерактивная страница `visual-lab.html`, доступная с телефона в той же сети: http://192.168.100.182:3002/visual-lab.html. Это отдельный эскиз для согласования, а не завершённая переработка полётного мира. Пользователь ещё не выбрал стиль или назначения эффектов. Переключатели страницы ничего не утверждают и не сохраняют в игре.

## Содержимое

- Три направления: сдержанный, кинематографичный, яркий стилизованный. Общая композиция позволяет сравнить цвета, свет, газовые облака и свечение.
- Процедурная иллюстративная планета с океаном, сушей, облаками и границей дня/ночи; звезда, луна, instanced астероиды и существующий жёлтый корабль. Научные каталоги не вызываются; объекты и расстояния демонстрационные, реальный масштаб игры не менялся.
- OrbitControls, приближение, пауза, возврат ракурса; HIGH/LOW, responsive portrait/landscape.
- Три кандидата EpicToonFX: SpinPortalBlue, ScanExplosion, Plexus. Только семь необходимых текстур и пять runtime JS (~786 KB вместе с определениями эффектов; manifest отдельно). WAV и полный каталог не копируются.
- Отдельный `EffectsPreview` управляет lazy import, одним активным эффектом, отменой устаревших выборов, disposal, particle budgets 1200 HIGH / 450 LOW. `groundY:null`, audio off. Three 0.160.1 сохранён; WebGLRenderer без новой зависимости.

Модули: `src/tools/visual-lab/{PreviewScene,EffectsPreview,materials,directions,main}.ts`, стили рядом. Vendor и происхождение: `src/vendor/epic-fx/`. Изменение исходного runtime только одно: URL ресурсов явно передаётся конструктору вместо default, относящегося к прежней структуре папок. SHA256 оригинальных и локальных файлов сохранены. `scripts/prepare-fx-preview.mjs` повторяет подготовку из предоставленной библиотеки без её изменения.

## Проверки

- Build / TypeScript / space-only guard PASS, без Vite warnings.
- 4/4 Playwright PASS: HIGH и LOW, все стили/эффекты, переключение качества, пауза, повторные циклы освобождения ресурсов, быстрые перекрывающиеся выборы, отсутствие API-каталогов/аудио на странице.
- HIGH/LOW guest entry в основную игру PASS; основной entry не загружает visualLab/epic-fx/assets FX.
- Ошибок и предупреждений браузера в compatibility tests: 0. После прогрева включение/выключение эффектов не накапливает geometry/texture counts. JSON и скриншоты `*-verified*` относятся к последней проверенной версии; прочие PNG/initial-probe — первый проход.
- Телефонный layout проверен браузерной эмуляцией 844×390 и 390×844. Физический телефон и его FPS пользователь пока не подтвердил.
- LAN proxy разрешает переход по внешней ссылке на `/` и `/visual-lab.html`, продолжает проверять Host/Origin, блокировать cross-site API и методы кроме GET/HEAD. Проверка: `node scripts/verify-lan-preview.mjs 192.168.100.182`.

Bundle: visualLab 21.70 KB JS / 8.75 gzip + 8.20 KB CSS / 2.46 gzip, lazy EpicFX 34.69 KB / 11.69 gzip. Библиотека эффектов присутствует в локальном dist для просмотра, но основная игра её не запрашивает. Публичной публикации не было. Фоновый LAN helper и production preview должны оставаться запущенными.

## Следующий шаг

Получить выбор пользователя по интерактивной странице, затем применить утверждённое направление к настоящему полётному миру модульно. Астероиды, туманности и аномалии в эскизе не означают, что они уже стали игровыми локациями; это последующая работа после выбора.
