## Historical material

[Verification archive](phases_archive/README.md) groups completed stages and their evidence. [Plans](plans/) preserve completed implementation checklists. [Research](research/) contains dated design/source investigations; proposals there are not statements that a feature has shipped.

Screenshots and compact reports are retained in Git. Full local recordings, temporary builds, source backups, scientific databases, guest saves and credentials are not part of source publication.
